# 100 長い仕様を確認する

## 目的

本文のスクロール、保存時の表示位置、三桁の番号順を確認します。

## 表示する内容

### 1. 目的

このページを見た聞き手に、何を理解してほしいかを確認します。文章が長くなる場合は、目的と補足を分けて読みます。

### 2. 前提

対象者の知識、発表の制約、前のページとのつながりを明確にします。未確定の前提は、実装前に確認できるよう残します。

### 3. 文章

見出しと本文で同じことを繰り返していないか、言い換えで情報量を増やしていないかを確認します。

### 4. 数値

数字の根拠、比較対象、集計期間を確認します。このサンプルには、実際の統計や実績は含みません。

### 5. 図

図のラベル、矢印、表示順で意図が伝わるかを確認します。ラベルが長い場合は、説明を本文に分けます。

### 6. コード

コードのどの部分を説明したいかを確認します。長い行はコードブロック内で横スクロールして読めます。

```text
仕様を読む → 目的を確認する → 表示内容を確認する → 未確定事項を整理する → レイアウトを確認する → 承認後にページを実装する
```

## レイアウト

このファイルを開き、本文を下までスクロールしてから文章を編集・保存すると、位置を保ったまま更新されることを確認できます。

## 振る舞い

`End` でこの仕様へ移動します。最後のページでは「次へ」が無効になります。`Home` で最初へ戻れます。

## 維持すること

サンプルの番号は `01`、`02`、`100` の順に並びます。
