# 02 表・コード・チェックリスト

## 目的

ox-contentで描画される文章と構造を確認します。

## 表示する内容

| 要素                             | 確認したいこと     |
| -------------------------------- | ------------------ |
| **太字**・_斜体_・~~取り消し線~~ | 強調の見え方       |
| `inline code`                    | 本文とコードの区別 |
| 表                               | 列と行の読みやすさ |

- [x] 目的を確認
- [ ] レイアウトを確認
- [ ] 未確定事項を整理

## レイアウト

```vue
<DeckSlide section-label="仕様レビュー" title="一枚につき、ひとつの主題">
  <p>このページで伝える内容をここに置きます。</p>
</DeckSlide>
```

> コードやHTMLは、ビューア内で実行せず内容を読んで確認します。

## 振る舞い

なし。

## 維持すること

内容を確定してから、ページ実装へ進みます。
